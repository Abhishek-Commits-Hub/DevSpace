# DevSpace

DevSpace is a personal developer workspace that brings my portfolio and a few useful frontend features together in one website.

I built this project as part of my frontend development internship to practice working with HTML, CSS and JavaScript in a more complete project instead of building separate small demos.

## What it includes

* Personal portfolio with About, Projects and Contact sections
* Task Manager for adding, editing, completing and deleting tasks
* Task search and filtering
* LocalStorage support so tasks stay saved after refreshing the page
* Product listing section with real product images
* Product search and category filtering
* Product sorting by price, rating and name
* Smooth card rearrangement animation when filtering and sorting
* Responsive layout for desktop, tablet and mobile screens

## Projects

The portfolio section currently features:

* **LeetMetric** – Coding dashboard for tracking and visualizing LeetCode progress.
* **Weather Quiz Dashboard** – Weather dashboard combined with an interactive quiz.
* **CareerConnect** – Career platform for exploring job opportunities and submitting applications.

## How to Run

No installation or setup is required.

1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Start using the website.

For the best development experience, the project can also be opened using VS Code with the Live Server extension.
